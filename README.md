# Paletter

Create palette sheets: named color stacks arranged in a grid, exportable as PNG.

## Run (web)

```bash
npm install
npm run dev
```

## Desktop app

```bash
npm run electron:dev      # development window
npm run electron:build    # Windows .exe into release/
```

- **Portable:** `release/Paletter-Portable-1.0.0.exe` (no install)
- **Installer:** `release/Paletter Setup 1.0.0.exe`

Closing the window quits the app completely.
